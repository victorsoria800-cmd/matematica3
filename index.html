Concepto

¿Qué es un polinomio?

Un polinomio es una expresión algebraica de la forma:

P(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x + a₀

donde aₙ ≠ 0 es el coeficiente líder y n es el grado del polinomio.

Ejemplo resuelto

Suma: P(x) = 3x² + 2x − 1 y Q(x) = x² − 5x + 4

Paso 1.

Agrupamos términos semejantes:

Paso 2.(3+1)x² + (2−5)x + (−1+4)
Resultado:4x² − 3x + 3
Ejemplo resuelto

Multiplicación: (x + 2)(x − 3)

Distributiva:x·x + x·(−3) + 2·x + 2·(−3)
= x² − 3x + 2x − 6
Resultado:x² − x − 6
Método

¿Cómo aplicar la Regla de Ruffini?

Para dividir P(x) por (x − a): se escriben los coeficientes de P(x) en una fila, se opera con el valor a, y el último número es el resto.

1) Escribir coeficientes (incluir 0 para términos faltantes)
2) Bajar el primer coeficiente
3) Multiplicar por a, sumar al siguiente
4) Repetir → último valor = RESTO

Teorema del Resto

Si P(x) se divide por (x − a),
el resto = P(a)

No hace falta dividir. Basta evaluar el polinomio en x = a.

Ejemplo 1

P(x) = x³ − 2x² + 3x − 4, divisor (x − 1). Encontrar el resto.

P(1) = 1 − 2 + 3 − 4 = −2
Resto = −2
Ejemplo 2

P(x) = x³ + kx − 6. Si x = 2 es raíz, ¿cuánto vale k?

8 + 2k − 6 = 0 → k = −1

Método de Gauss

¿Cómo funciona el método de Gauss?

F_i ↔ F_j (intercambiar filas)
F_i → k·F_i (multiplicar por escalar k≠0)
F_i → F_i + k·F_j (sumar múltiplo de otra fila)

¿Qué es una función?

Una función f: A → B asigna a cada elemento del dominio A exactamente un elemento del codominio B.

f(x) = 2x + 1 → a cada x le corresponde un único valor
Ejemplo — Dominio

f(x) = √(x − 3). ¿Cuál es el dominio?

x − 3 ≥ 0 → x ≥ 3

¿Qué son los números irracionales?

Son números que no pueden expresarse como fracción. Su decimal es infinito y no periódico.

Ejemplos: √2, √3, π (Pi), e
Extracción de Factores

Simplificar: √50

50 = 2 · 5²
√50 = 5√2

Números Complejos

Un número complejo tiene la forma z = a + bj, donde a es la parte real, b la parte imaginaria y j = √(−1) (en electrónica se usa j en lugar de i).

Potencias de j

PotenciaValor

j²−1
j³−j
j⁴1
j⁵j (ciclo se repite)

Regla: dividí el exponente por 4 y usá el resto: 0→1, 1→j, 2→−1, 3→−j.

Suma y Resta

Se suman/restan partes reales entre sí e imaginarias entre sí:

(a + bj) ± (c + dj) = (a±c) + (b±d)j

Ejemplo: (3 + 5j) + (2 − 3j) = 5 + 2j

Ejemplo: (7 − 2j) − (4 + 6j) = 3 − 8j

Multiplicación

Se aplica la propiedad distributiva y se reemplaza j² = −1:

(a + bj)(c + dj) = ac + adj + bcj + bdj² = (ac−bd) + (ad+bc)j

Ejemplo: (2 + 3j)(1 − 4j) = 2 − 8j + 3j − 12j² = 2 − 5j + 12 = 14 − 5j

Conjugado: z̄ = a − bj → z · z̄ = a² + b² (número real)

División

Se multiplica numerador y denominador por el conjugado del denominador:

(a+bj)/(c+dj) = [(a+bj)(c−dj)] / (c²+d²)

Ejemplo: (3+2j)/(1+4j) · (1−4j)/(1−4j) = (3−12j+2j−8j²)/(1+16) = (11−10j)/17 = 0,647 − 0,588j

Forma Polar ↔ Rectangular

Rectangular → Polar: z = a + bj → z = r∠θ, donde r = |z|, θ = arg(z)

Polar → Rectangular: z = r∠θ → a = r·cos(θ), b = r·sin(θ)

Ejemplo: z = 3 + 4j → r = √(9+16) = 5, θ = arctan(4/3) ≈ 53,13° → z = 5∠53,13°

Ejemplo: z = 10∠30° → a = 10·cos30° ≈ 8,66, b = 10·sin30° = 5 → z = 8,66 + 5j

Producto y División en Forma Polar (Fasores)

Producto: r₁∠θ₁ · r₂∠θ₂ = (r₁·r₂)∠(θ₁+θ₂)

División: r₁∠θ₁ / r₂∠θ₂ = (r₁/r₂)∠(θ₁−θ₂)

Ejemplo (Ley de Ohm fasorial): V = Z · I → 10∠30° · 2∠45° = 20∠75°

Ejemplo: Z = V/I = 120∠0° / 6∠−30° = 20∠30° Ω

Fórmula de Euler

z = r·e^(jθ) = r(cosθ + j·sinθ)

Esta forma es fundamental en análisis de circuitos AC y transformadas de Fourier.
