Concepto

¿Qué es un polinomio?

Un polinomio es una expresión algebraica de la forma:

P(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x + a₀

donde aₙ ≠ 0 es el coeficiente líder y n es el grado del polinomio.

Ejemplo resuelto

Suma: P(x) = 3x² + 2x − 1 y Q(x) = x² − 5x + 4

Paso 1. Agrupamos términos semejantes:
(3+1)x² + (2−5)x + (−1+4)

Paso 2.
Resultado: 4x² − 3x + 3

Ejemplo resuelto

Multiplicación: (x + 2)(x − 3)

Distributiva: x·x + x·(−3) + 2·x + 2·(−3)
= x² − 3x + 2x − 6

Resultado: x² − x − 6

¿Cómo aplicar la Regla de Ruffini?

Para dividir P(x) por (x − a): se escriben los coeficientes de P(x) en una fila, se opera con el valor a, y el último número es el resto.

  • 1) Escribir coeficientes (incluir 0 para términos faltantes)
  • 2) Bajar el primer coeficiente
  • 3) Multiplicar por a, sumar al siguiente
  • 4) Repetir → último valor = RESTO

Teorema del Resto

Si P(x) se divide por (x − a),
el resto = P(a)

No hace falta dividir. Basta evaluar el polinomio en x = a.

Ejemplo 1

P(x) = x³ − 2x² + 3x − 4, divisor (x − 1). Encontrar el resto.

P(1) = 1³ − 2(1)² + 3(1) − 4
P(1) = 1 − 2 + 3 − 4 = −2
Resto = −2

Ejemplo 2

P(x) = x³ + kx − 6. Si x = 2 es raíz, ¿cuánto vale k?

Si x = 2 es raíz, el resto es 0 (P(2) = 0).
2³ + k(2) − 6 = 0
8 + 2k − 6 = 0 → 2k = −2 → k = −1

Método 1 — Sustitución

Resolver: 2x + y = 7 y x − y = 2

Paso 1. Despejamos x de la 2.ª: x = y + 2
Paso 2. Sustituimos en la 1.ª:
2(y + 2) + y = 7 → 2y + 4 + y = 7 → 3y = 3 → y = 1
Paso 3. Hallamos x: x = 1 + 2 = 3
Solución: x=3, y=1

Método 2 — Eliminación

Resolver: 3x + 2y = 12 y x − 2y = 0

Sumamos las ecuaciones:
(3x + x) + (2y - 2y) = 12 + 0
4x = 12 → x = 3
Sustituyendo x=3: 3 - 2y = 0 → y = 3/2

Método de Gauss

¿Cómo funciona el método de Gauss?

Consiste en transformar la matriz del sistema en una matriz escalonada mediante operaciones elementales:

  • F_i ↔ F_j (intercambiar filas)
  • F_i → k·F_i (multiplicar por escalar k≠0)
  • F_i → F_i + k·F_j (sumar múltiplo de otra fila)

¿Qué es una función?

Una función f: A → B asigna a cada elemento del dominio A exactamente un elemento del codominio B.

f(x) = 2x + 1 → a cada x le corresponde un único valor

Ejemplo — Dominio

f(x) = √(x − 3). ¿Cuál es el dominio?

El argumento de la raíz debe ser ≥ 0:
x − 3 ≥ 0 → x ≥ 3
Dominio: [3, +∞)

Factorizar: 6x³ − 9x² + 3x

3x es el común denominador:
3x(2x² − 3x + 1) = 3x(2x−1)(x−1)

Diferencia de cuadrados

Factorizar: 4x² − 25

Usa la fórmula (a² - b²) = (a+b)(a-b):
(2x)² − 5² = (2x + 5)(2x − 5)

Trinomio cuadrado perfecto

Factorizar: x² + 6x + 9

Busca la forma (a + b)² = a² + 2ab + b²:
x² + 2(3)x + 3² = (x + 3)²

Concepto

¿Qué son los números irracionales?

Son números que no pueden expresarse como fracción. Su decimal es infinito y no periódico.

Ejemplos: √2, √3, π (Pi), e

Extracción de Factores

Simplificar: √50

Factorizamos 50: 50 = 2 · 5²
√50 = √(2 · 5²) = 5√2

Suma de radicales

Simplificar: 3√2 + 5√2

Se suman los coeficientes cuando el radicando es igual:
(3 + 5)√2 = 8√2

Multiplicación de radicales

Calcular: √3 · √12

Propiedad: √a · √b = √(a · b)
√3 · √12 = √36 = 6

Racionalización de Denominadores

Quitar la raíz del denominador: 1 / √2

Multiplicamos arriba y abajo por √2:
(1 · √2) / (√2 · √2) = √2 / 2

¿Qué es un número complejo?

Es un número de la forma z = a + bi, donde a es la parte real y bi la parte imaginaria.

i = √(-1)

Potencias de i

i⁰1
i¹i
i²-1
i³-i

Suma y Resta

(3 + 2i) + (1 + 4i)

Sumamos reales con reales e imaginarios con imaginarios:
(3+1) + (2+4)i = 4 + 6i

Módulo de un complejo

|3 + 4i|

Fórmula: |z| = √(a² + b²)
√(3² + 4²) = √(9+16) = √25 = 5
