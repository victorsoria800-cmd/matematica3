Concepto

¿Qué es un polinomio?

Un polinomio es una expresión algebraica de la forma:

P(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x + a₀

donde aₙ ≠ 0 es el coeficiente líder y n es el grado del polinomio.

Ejemplo resuelto

Suma: P(x) = 3x² + 2x − 1 y Q(x) = x² − 5x + 4

Paso 1.

Agrupamos términos semejantes (mismo grado):

Paso 2. (3+1)x² + (2−5)x + (−1+4)
Resultado: 4x² − 3x + 3
Ejemplo resuelto

Multiplicación: (x + 2)(x − 3)

Distributiva: x·x + x·(−3) + 2·x + 2·(−3)
= x² − 3x + 2x − 6
Resultado: x² − x − 6
Método

¿Cómo aplicar la Regla de Ruffini?

Para dividir P(x) por (x − a): se escriben los coeficientes de P(x) en una fila, se opera con el valor a, y el último número es el resto.

1) Escribir coeficientes de P(x) (incluir 0 para términos faltantes)
2) Bajar el primer coeficiente
3) Multiplicar por a, sumar al siguiente coeficiente
4) Repetir hasta el final → el último valor = RESTO
Ejemplo 1

Dividir x³ − 6x² + 11x − 6 entre (x − 1)

Coeficientes: 1, −6, 11, −6  |  a = 1

↓ 1↓ −5↓ 6
1−560
Cociente: x² − 5x + 6  |  Resto: 0

Resto = 0 → (x−1) es factor. P(x) = (x−1)(x−2)(x−3)

Enunciado

Teorema del Resto

Si P(x) se divide por (x − a),
el resto = P(a)

No hace falta dividir. Basta evaluar el polinomio en x = a.

Corolario: Si P(a) = 0, entonces (x − a) es factor de P(x) y a es raíz.

Ejemplo 1

P(x) = x³ − 2x² + 3x − 4, divisor (x − 1). Encontrar el resto.

Aplicamos T. del Resto:

Evaluamos P(1):

P(1) = 1 − 2 + 3 − 4 = −2
Resto = −2

(sin necesidad de dividir)

P(3) = 0 → x = 3 SÍ es raíz.

Ejemplo 3 — hallar k

P(x) = x³ + kx − 6. Si x = 2 es raíz, ¿cuánto vale k?

P(2) = 0 (porque 2 es raíz)

Método de Gauss — Escalera

¿Cómo funciona el método de Gauss?

Se escribe el sistema como matriz ampliada [A|b] y se aplican operaciones elementales de fila para llegar a forma triangular superior (escalera). Luego se resuelve de abajo hacia arriba (sustitución regresiva).

Operaciones permitidas:
F_i ↔ F_j     (intercambiar filas)
F_i → k·F_i    (multiplicar por escalar k≠0)
F_i → F_i + k·F_j   (sumar múltiplo de otra fila)

Sistema: x+y+z=6 | 2x+y−z=3 | x−y+z=4

Matriz ampliada inicial:
[ 1 1 1 | 6 ]
[ 2 1 −1 | 3 ]
[ 1 −1 1 | 4 ]
F2 → F2 − 2·F1:
[ 1 1 1 | 6 ]
[ 0 −1 −3 |−9 ]
[ 1 −1 1 | 4 ]
F3 → F3 − F1:
[ 1 1 1 | 6 ]
[ 0 −1 −3 |−9 ]
[ 0 −2 0 |−2 ]
F3 → F3 − 2·F2:
[ 1 1 1 | 6 ]
[ 0 −1 −3 |−9 ]
[ 0 0 6 |16 ]
Sustitución regresiva:
6z=16 → z=8/3
−y−3(8/3)=−9 → −y=−9+8=−1 → y=1
x+1+8/3=6 → x=6−1−8/3=7/3
Solución: x=7/3, y=1, z=8/3
Concepto

¿Qué es una función?

Una función f: A → B asigna a cada elemento del dominio A exactamente un elemento del codominio B.

f(x) = 2x + 1  →  a cada x le corresponde un único valor
Ejemplo — Dominio e Imagen

f(x) = √(x − 3). ¿Cuál es el dominio?

Condición:

El radicando debe ser ≥ 0:

x − 3 ≥ 0 → x ≥ 3
Dominio: [3, +∞)
Imagen: [0, +∞) (raíz siempre ≥ 0)
Ejemplo — Evaluar función

f(x) = x² − 2x + 1. Calcular f(3) y f(−1).

f(3) = 9 − 6 + 1 = 4
f(−1) = 1 + 2 + 1 = 4
Factor común

Factorizar: 6x³ − 9x² + 3x

Factor común:

El MCD de 6, 9, 3 es 3 y la menor potencia de x es x¹.

3x(2x² − 3x + 1)

El trinomio se factoriza: 3x(2x−1)(x−1)

Diferencia de cuadrados

Factorizar: 4x² − 25

Fórmula: a² − b² = (a+b)(a−b)
4x² = (2x)²   25 = 5²
Resultado: (2x+5)(2x−5)
Trinomio cuadrado perfecto

Factorizar: x² + 6x + 9

Fórmula: a² + 2ab + b² = (a+b)²
x² + 2·x·3 + 3² = (x+3)²
Casos combinados — estrategia

¿Cómo factorizar completamente?

Muchas expresiones requieren más de un caso en secuencia. El orden recomendado es:

1° Extraer factor común (siempre primero si existe)
2° Reconocer el caso dentro del paréntesis:
   · Diferencia de cuadrados: a²−b²=(a+b)(a−b)
   · Trinomio cuadrado perfecto: a²±2ab+b²=(a±b)²
   · Trinomio general: (x+p)(x+q) donde p·q=c y p+q=b
   · Suma/diferencia de cubos
3° Verificar si algún factor sigue siendo factorizable
Caso combinado 1 — FC + Dif. cuadrados

Factorizar completamente: 5x³ − 20x

Paso 1 — Factor común: 5x(x²−4)
Paso 2 — Diferencia de cuadrados: x²−4=(x+2)(x−2)
Resultado final: 5x(x+2)(x−2) ← se aplicaron DOS casos
Caso combinado 2 — FC + Trinomio

Factorizar completamente: 4x³ − 4x² − 8x

Paso 1 — Factor común: 4x(x²−x−2)
Paso 2 — Trinomio:

Buscamos p y q tal que p+q=−1 y p·q=−2: son −2 y +1

4x(x−2)(x+1)
Resultado final: 4x(x−2)(x+1) ← DOS casos encadenados
Caso combinado 3 — Dif. cuadrados doble

Factorizar completamente: x⁴ − 81

Paso 1: x⁴−81 = (x²)²−9² = (x²+9)(x²−9)
Paso 2:

¿Se puede seguir? x²+9 no factoriza en reales, pero x²−9 sí:

x²−9=(x+3)(x−3)
Resultado final: (x²+9)(x+3)(x−3) ← DOS casos de dif. de cuadrados
Concepto

¿Qué son los números irracionales?

Son números que no pueden expresarse como una fracción de dos enteros. Su expresión decimal es infinita y no periódica.

Ejemplos: √2, √3, π (Pi), e
Extracción de Factores

Simplificar radical: √50

Paso 1.

Factorizamos el 50: 50 = 2 · 5²

Paso 2. √50 = √(2 · 5²) = 5√2
Resultado: 5√2
Concepto

La Unidad Imaginaria

Surge para resolver raíces de números negativos. Se define como:

i = √−1   →   i² = −1

Un número complejo tiene la forma: z = a + bi

Operaciones y Gráfica

Suma: (2 + 3i) + (1 + 4i)

Paso 1.

Sumamos partes reales: 2 + 1 = 3

Paso 2.

Sumamos partes imaginarias: 3i + 4i = 7i

Resultado: 3 + 7i
Gráfica:

Se representa como el punto (3, 7) en el plano complejo (eje X = Real, eje Y = Imaginario).
